Wix setup notes

Place the snippet in your site's body, not an Embed block. Go to Settings → Advanced → Custom Code → Add Custom Code. Set "Place Code in" to Body - end. Choose specific pages if you only want the bubble on certain pages. (Custom Code requires a paid Wix plan.) Pasting into an on-page Embed → Custom Code element puts the bubble inside a tiny iframe; the floating position only works when the script lives in the top frame.

For password-protected pages, gate the bubble by either:

  • &wait_for=<selector> — mount when a CSS selector starts matching (e.g. an element only rendered post-login).
  • &wait_until_gone=<selector> — mount when a selector stops matching (e.g. the password dialog disappears). Open DevTools in the locked state, find an element on the dialog, copy its class or id.

The widget logs to the browser console when waiting and when it mounts, so you can verify the gate in DevTools.
