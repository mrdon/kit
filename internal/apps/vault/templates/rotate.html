Rotate the vault master password

Rotation replaces the team's shared master password with a new one. You need the old password — rotation unwraps the existing vault key under the old password and re-wraps it under the new password, so every stored secret keeps working.

After rotation, share the new password with the team out-of-band. Open tabs on other devices will re-lock within seconds and prompt for the new password.

If the old password is lost, use Destroy & reset instead.
